# TODO管理アプリ

## 概要
Javaの勉強のために作成した、TODOを管理するアプリです。

## 制作目的
・Javaの基本的な文法に慣れるため  
・クラスやメソッドの使い方を理解するため  

## 使用技術
・Java  
・Swing  

## 機能
・TODOを追加する  
・TODOを一覧で表示する  
・TODOを削除する  

## 工夫した点
・処理ごとにクラスを分けて、分かりやすくなるようにしました  

## 難しかった点
・ボタンを押したときの動きを作るところが難しかったです  

## 今後やりたいこと
・TODOをファイルに保存できるようにしたいです
